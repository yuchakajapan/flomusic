# flomusic

曲の「いいところ」を自動で見つけて切り出す、ブラウザだけで動く音声ツールです。

**https://flomusic.forworld.workers.dev**

音声の解析も書き出しも、すべてブラウザの中で完結します。**曲がサーバーに送られることは一切ありません。**
このリポジトリを公開しているのは、その主張をコードで確認できるようにするためです。

---

## できること

### アタマ出し

曲を解析して、盛り上がりが始まる位置・音圧が一気に立ち上がる位置（ドロップ）・展開が切り替わる位置を検出し、
そこから始まる音源を書き出します。動画のBGMを、静かなイントロではなく一番刺さる位置から始めたいときに。

### ループ作成

「一周して先頭に戻っても違和感がない区間」を探します。長さは4 / 8 / 16小節から選べるので、
何周させても拍がずれません。指定秒数まで繰り返した1本のファイルとしても書き出せます。

どちらも、波形上のつまみをドラッグして開始・終了を手で調整できます。
ドラッグ中は拍・小節頭にスナップし、Shiftを押しながらで吸着を解除できます。

書き出しは WAV（無劣化）と MP3（128 / 192 / 320kbps）。商用利用可・クレジット表記不要です。

## しくみ

音楽生成AIは使っていません。すべて信号処理です。

1. `OfflineAudioContext` で 22050Hz モノラルに変換
2. FFT（窓1024 / ホップ256）で RMS・スペクトルフラックス・クロマ12次元・メル20帯を抽出
3. クロマ＋メルの特徴ベクトルから帯状の自己相似行列を作り、
   チェッカーボード核を畳み込んで構成の切れ目（Foote novelty）を検出
4. 音量の dB 差から「盛り上がり」（4秒窓）と「ドロップ」（1.3秒窓）を判定
5. オンセット強度の自己相関でテンポを推定し、低域エネルギーで小節頭の位相を決める
6. 候補位置を拍・小節頭にスナップして切り出し

ループ探索は、終点の直前と始点の直前がどれだけ似ているか（繋いだ瞬間に段差が出ないか）に加えて、
直後どうしの類似（2点が曲の中で同じ位置づけか）も見ています。
後者を入れないと、サビ頭のように「手前だけ雰囲気が違う」点を取りこぼします。

## 構成

```
src/
  app.js        エンジン本体（解析・描画・書き出し）
  app.css       全ページ共通のスタイル
  tool.html     ツールUIのマークアップ（全ページで共有）
  pages.py      ページごとの文言・更新履歴・運営者情報
  build.py      public/ を生成する
public/         生成物。Cloudflare Workers にそのまま配信される
wrangler.toml   デプロイ設定
起動.bat        ローカル確認用（http://localhost:8899 で開く）
```

`index.html` は `src/` から生成されるため、直接編集しないでください。

### ビルドと公開

```bash
python src/build.py     # public/ を再生成
npx wrangler deploy     # Cloudflare Workers へ公開
```

ローカルで確認するときは `起動.bat` を実行してください（`http://localhost:8899`）。
`file://` で直接開くと、ブラウザの仕様で「保存先フォルダの指定」が使えません
（opaque origin のため File System Access API が拒否されます）。
