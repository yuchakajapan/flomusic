「サビ」を機械はどう探しているか

サビには共通する特徴があります。音量が大きい、低音が厚い、その直前で一度ためを作る、 そして曲の中で複数回くり返される。flomusic はこれらを別々に測っています。

音量が数秒かけて上がっていく箇所は盛り上がり開始、急に跳ね上がる箇所はドロップ、 和音や音色の傾向がガラッと変わる箇所は展開の切り替わりとして分類します。 さらに、切り出した直後のエネルギーが高いものには🔥を付けています。 サビを狙うなら、🔥が付いた候補から聴くのが近道です。

頭が不自然にならない理由

秒数だけで機械的に切ると、たいてい拍の途中から始まってしまい、聴いた瞬間に気持ち悪さが出ます。 flomusic はテンポと小節頭を推定して、切り出し位置を拍・小節の頭に吸着させています。 そのまま動画に置いても、頭が転ばずに鳴りはじめます。

検出がずれていたら手で直せます

サビの入りは曲によって癖があるので、自動検出が1拍ずれることもあります。 その場合は波形の端をドラッグして調整してください。拍に吸着しながら動くので、耳で合わせるだけで済みます。 Shiftを押しながらドラッグすれば吸着なしで細かく詰められます。

ショート動画のBGMに

縦型ショートは最初の1秒で見られるかが決まります。イントロから使うと、その勝負どころが 静かなパッドの音で消えます。サビ頭から始めれば、開始と同時に一番強い部分が鳴ります。 15秒・30秒・60秒のプリセットを用意しているのはこのためです。

安全性について

音声の解析も書き出しも、すべてあなたのブラウザの中で完結します。 曲がサーバーに送られることは一切ありません。アカウント登録も不要で、 読み込んだ音源はページを閉じた時点で消えます。
なお、訪問数の把握のために Cloudflare Web Analytics を使用しています。 これはCookieを使わず、個人を特定しません。記録されるのはページの表示回数や参照元といった統計情報だけで、 あなたが読み込んだ音源やその内容は一切送信されません。
この主張は、口約束ではなくコードで確認できます。 flomusic のソースコードはすべて公開しています。 GitHubでソースコードを見る

商用利用について

書き出した音源は商用利用できます。 YouTube・広告・クライアントワーク・販売物など、用途の制限はありません。 クレジット表記も不要です。flomusic側が利用料や権利を主張することは一切ありません。
ただし、元の楽曲の権利は元の権利者にあります。ご自身が権利を持つ音源、 または利用許諾を得た音源でお使いください。切り出しても原曲の著作権は消えません。

対応形式

読み込みは MP3 / WAV / M4A / OGG / FLAC など、お使いのブラウザが再生できる音声ファイル。 書き出しは WAV（無劣化）と MP3（128 / 192 / 320kbps）から選べます。 DRMで保護された曲は読み込めません。

MP3エンコードに lamejs（LGPL-3.0）を使用しています。
