普通のMP3カッターとの違い

多くのカットツールは、指定した秒数のところで機械的に切ります。その結果、拍の途中でぶつ切りになり、 再生した瞬間にリズムが転びます。flomusic は先に曲のテンポと小節の位置を解析してから切るので、 切り口が音楽的な区切りに揃います。

もうひとつの違いは、どこを切るべきかを提案してくれることです。読み込むと自動で 「盛り上がりが始まる位置」「音圧が立ち上がる位置」「展開が変わる位置」に印が付くので、 波形をゼロから探す必要がありません。

アップロードしないので速い

オンラインのカットツールの多くは、ファイルをサーバーに送って処理し、結果をダウンロードさせます。 50MBの曲なら、送って待って受け取るだけで時間がかかります。 flomusic はすべてブラウザの中で処理するので、アップロードの待ち時間がゼロです。 同時に、曲が外部に送られないという安心もあります。

動画の尺にBGMを合わせる

「動画が43秒だからBGMも43秒にしたい」という場合は、カスタムで秒数を指定してください。 フェードアウトの秒数も指定できるので、終わりがブツ切りにならず自然に消えます。 逆に曲が足りない場合は、ループBGM作成で必要な尺まで繰り返した1本を作れます。

WAVとMP3、どちらで書き出すか

動画編集ソフトに取り込むならWAVを推します。無劣化なので、そのあと動画側で再エンコードされても 音質の劣化が重なりません。ファイルサイズを抑えたい、そのまま配布したいという場合は MP3を選んでください。192kbpsならWAVの約8分の1のサイズになります。

安全性について

音声の解析も書き出しも、すべてあなたのブラウザの中で完結します。 曲がサーバーに送られることは一切ありません。アカウント登録も不要で、 読み込んだ音源はページを閉じた時点で消えます。
なお、訪問数の把握のために Cloudflare Web Analytics を使用しています。 これはCookieを使わず、個人を特定しません。記録されるのはページの表示回数や参照元といった統計情報だけで、 あなたが読み込んだ音源やその内容は一切送信されません。
この主張は、口約束ではなくコードで確認できます。 flomusic のソースコードはすべて公開しています。 GitHubでソースコードを見る

商用利用について

書き出した音源は商用利用できます。 YouTube・広告・クライアントワーク・販売物など、用途の制限はありません。 クレジット表記も不要です。flomusic側が利用料や権利を主張することは一切ありません。
ただし、元の楽曲の権利は元の権利者にあります。ご自身が権利を持つ音源、 または利用許諾を得た音源でお使いください。切り出しても原曲の著作権は消えません。

対応形式

読み込みは MP3 / WAV / M4A / OGG / FLAC など、お使いのブラウザが再生できる音声ファイル。 書き出しは WAV（無劣化）と MP3（128 / 192 / 320kbps）から選べます。 DRMで保護された曲は読み込めません。

MP3エンコードに lamejs（LGPL-3.0）を使用しています。
