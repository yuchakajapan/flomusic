ループBGMが「不自然になる」理由

曲の適当な10秒を切り出して繰り返すと、たいてい繋ぎ目で違和感が出ます。原因は2つあります。

ひとつは拍のズレ。切り出した長さが小節の整数倍でないと、繰り返すたびにリズムが前後にずれていき、 2周目3周目で完全に破綻します。flomusic が長さを小節単位でしか切らないのはこのためです。

もうひとつは音の繋がり。終わりの瞬間と始まりの瞬間で、鳴っている和音や音量が違うと、 戻った瞬間に「段差」として聞こえます。flomusic は、終点の直前と始点の直前がどれだけ似ているかを 曲全体で総当たりに比べ、段差が出ない組み合わせだけを候補に出しています。

繋ぎ目は耳で確かめられます

候補の▶ボタンは、切り出した区間を実際にループ再生します。数周聴いて継ぎ目が気にならなければ、 それが当たりです。スコアの数字より、耳で判断するほうが確実です。

候補の位置が惜しいときは、波形の両端をドラッグして手で調整できます。ドラッグ中は拍と小節頭に吸着するので、 手で動かしても拍が崩れません。動かすと繋ぎ目の自然さが自動で測り直されます。

作業用BGM・配信の下敷きに

1周ぶんのファイルは、動画編集ソフトやDAWに置いて無限に繰り返す使い方に向いています。 一方「秒数を指定」で書き出すと、指定した長さまで繰り返した1本のファイルになります。 尺が決まっている動画に置くだけで済むので、編集の手間が減ります。

安全性について

音声の解析も書き出しも、すべてあなたのブラウザの中で完結します。 曲がサーバーに送られることは一切ありません。アカウント登録も不要で、 読み込んだ音源はページを閉じた時点で消えます。
なお、訪問数の把握のために Cloudflare Web Analytics を使用しています。 これはCookieを使わず、個人を特定しません。記録されるのはページの表示回数や参照元といった統計情報だけで、 あなたが読み込んだ音源やその内容は一切送信されません。
この主張は、口約束ではなくコードで確認できます。 flomusic のソースコードはすべて公開しています。 GitHubでソースコードを見る

商用利用について

書き出した音源は商用利用できます。 YouTube・広告・クライアントワーク・販売物など、用途の制限はありません。 クレジット表記も不要です。flomusic側が利用料や権利を主張することは一切ありません。
ただし、元の楽曲の権利は元の権利者にあります。ご自身が権利を持つ音源、 または利用許諾を得た音源でお使いください。切り出しても原曲の著作権は消えません。

対応形式

読み込みは MP3 / WAV / M4A / OGG / FLAC など、お使いのブラウザが再生できる音声ファイル。 書き出しは WAV（無劣化）と MP3（128 / 192 / 320kbps）から選べます。 DRMで保護された曲は読み込めません。

MP3エンコードに lamejs（LGPL-3.0）を使用しています。
